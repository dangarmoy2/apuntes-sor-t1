## ⌨️ Comandos y pasos importantes

- `pwd` — Comprueba la ruta del directorio actual en la terminal para verificar que estamos dentro de `.../Boveda_SOR/01_Practicas`.
- `git clone git@github.com:TU-USUARIO/bloque-0-prerequisitos.git B0_Prerrequisitos` — Clona por SSH tu copia del repositorio de Prerrequisitos asignándole el nombre de carpeta `B0_Prerrequisitos`.
- `git clone https://github.com/TU-USUARIO/bloque-1-entorno.git B1_Entorno` — Clona por HTTPS tu copia del repositorio del Bloque 1 renombrando la carpeta a `B1_Entorno`.
- `git clone git@github.com:TU-USUARIO/bloque-2-ubuntu-local.git B2_Ubuntu_Local` — Clona por SSH tu copia del repositorio del Bloque 2 (Boochan) en la carpeta `B2_Ubuntu_Local`.
- `git status` — Muestra el estado del repositorio local (archivos modificados, sin seguimiento o si la carpeta no es un repositorio Git válido).
- `git remote -v` — Muestra las URLs remotas configuradas para verificar que apuntan a tu usuario de GitHub y no al del profesor.
- `git add .` — Añade los archivos nuevos o modificados al área de preparación (*staging*).
- `git commit -m "Anadir mis datos de alumno"` — Guarda los cambios preparados en el historial del repositorio local con un mensaje.
- `git push` — Envía los commits locales a tu repositorio remoto en GitHub.

## 🤔 Respuestas a las preguntas

1. **¿Qué hace Use this template? Después de pulsarlo, ¿sobre qué repositorio trabajas, el mío o el tuyo?**
   Crea en tu propia cuenta de GitHub un repositorio nuevo e independiente con el mismo contenido inicial que la plantilla, pero con un historial propio. Después de pulsarlo, trabajas exclusivamente sobre **tu propio repositorio**, nunca sobre el del profesor.
2. **Te has bajado el Bloque 1 por HTTPS y no te ha pedido contraseña. ¿Por qué? ¿Cuándo sí te la habría pedido?**
   No pide contraseña porque el repositorio es **público**, por lo que cualquiera puede leerlo o clonarlo sin identificarse. Te habría pedido autenticación (token o clave SSH) si hubieras intentado hacer `git push` para escribir/subir cambios, o si el repositorio hubiera sido privado.
3. **En el Explorador, la carpeta del ZIP y la carpeta clonada se ven idénticas. ¿Qué tiene una que no tiene la otra, y qué tres cosas dejas de poder hacer sin ella?**
   La carpeta clonada tiene la carpeta oculta `.git` (que contiene todo el historial y la configuración del repositorio), mientras que el ZIP solo trae los ficheros sueltos. Sin la carpeta `.git` dejas de poder:
   - Consultar el estado o el historial del repositorio (`git status`, `git log`).
   - Recuperar archivos borrados o deshacer cambios (`git restore`).
   - Subir tus cambios o anotaciones a GitHub (`git push`).
4. **Anotas una duda en un fichero de la práctica, en el ordenador del aula. ¿Qué tienes que hacer para encontrarla el sábado en casa?**
   En el ordenador del aula debes guardar el cambio y subirlo a GitHub ejecutando `git add .`, `git commit -m "mensaje"` y `git push` dentro de la carpeta de esa práctica. Después, el sábado en casa, debes abrir la terminal en esa misma carpeta y ejecutar `git pull` para descargar el cambio.
